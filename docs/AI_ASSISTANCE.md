# AI assistance and accountability

Updated October 26, 2026. This statement describes the project's known use of generative AI and the checks contributors should make. It is a high-level disclosure, not a per-file attribution ledger.

## Known project use

Generative AI tools and coding assistants have been used to help develop software, edit documentation, organize research and draft evidence summaries. The project has not kept a complete historical record of every model, version or contribution. Where that provenance is unknown, we say so rather than reconstructing it from guesswork.

AI assistance is not independent scientific review, evidence that a source supports a claim, or validation of an animal's behavior. Research notes link to original sources and describe review depth; software tests show behavior on tested inputs, not biological truth. The maintainer and human contributors remain responsible for claims, code, rights, privacy, security and decisions.

## Contributor practice

For material AI assistance, disclose in the pull request what work it helped with, which tool or model and version if known, and what a person checked. Do not submit prompts or confidential work logs. Do not claim a missing model/version record is known. A contributor may work without generative AI.

Do not place private recordings, participant information, credentials, unpublished sensitive data or precise wildlife locations into an AI service. Do not use generated labels as ground truth, or generated interpretations as animal meaning. Check sources and data rights independently; review generated code for correctness, licensing, security and dependencies; run the relevant tests.

## Funder-specific rules

Funding agreements can impose stricter rules than this contributor policy. Read the exact current call before preparing any application or funded work. For example, NLnet policy v2.0, checked October 26, 2026, prohibits GenAI-written proposals and GenAI-produced artifacts in funded activities, and asks applicants to disclose significant pre-existing AI-generated code. Its [policy](https://nlnet.nl/foundation/policies/generativeAI/2.0/) and [FAQ](https://nlnet.nl/foundation/policies/generativeAI/faq/) apply to NLnet; they are not a universal rule for all open-source projects. Talk2Nature's current funding register marks CodeSupply as not recommended this cycle while work-package fit, team eligibility and historical codebase disclosure remain unresolved.
