# First dataset decision: match the corpus to the question

**Status:** decision brief, refreshed October 25, 2026. This is a literature and metadata assessment. No animal recordings or model weights were acquired or run, and no candidate has been approved for a Talk2Nature benchmark.

## Recommendation

Keep three goals separate:

For a bounded, already understood communication system, honeybee waggle-dance/follower data deserve independent review because they link a defined signal, observed receivers and feeder outcomes. The core association is already published and the archive spans one site, so this is not yet a novel or selected Talk2Nature task.

1. **Build the data and model workflow:** use Wytham Great Tit as the leading large-corpus *song-structure methods* candidate, if an independent reviewer identifies a non-duplicative task. A sensible scope is note/song structure or repertoire measurement with birds held out by individual. OpenWhistle is a separate large dolphin-audio candidate for whistle detection/type classification; because the authors already publish those benchmarks, any Talk2Nature task must add value beyond an unreviewed duplicate. Neither route establishes communication meaning.
2. **Ask a communication-adjacent biological question:** prioritize independent review of Egyptian fruit-bat interaction-context prediction. A caller-specific metadata check suggests a narrow new-caller evaluation may retain most filtered examples, but no split exists and the paper already reports subject-independent folds. Zebra-finch call-perception remains a separate high-value review lead with unresolved artifact and rights questions.
3. **Serve companion-animal carers:** keep budgerigars as a provisional Field Companion cohort, conditional on genuine access, an avian researcher and an approved, non-invasive protocol. This is a product/user path, not a substitute for an open benchmark corpus.

**Do not train a general animal-language model.** Large audio collections and language-model interfaces can help detect, cluster, describe or predict acoustic patterns. Those outputs do not establish what an animal intends or understands. A meaning claim needs independent behavioral evidence and a suitable receiver-response test.

## Candidate fit

| Candidate | What the data can help test | Why it is not a communication benchmark yet |
| --- | --- | --- |
| **Wytham Great Tit Song Dataset** | The authors report 109,963 prepared annotated songs, more than 1.16 million acoustic notes and over 400 wild birds. Useful for a carefully scoped song-structure methods exercise on the shared song files. | No receiver-response or meaning labels; one population and dawn-singing setting. A 2025 study already uses deep metric learning for repertoire similarity and song culture, so any task must add value. The OSF node declares CC BY 4.0 for the dataset record; the setup-code repository is separately MIT. The complete October 24 API tree has 23 files totaling 12,184,678,510 bytes (14 under `data/` and nine under `docs/`); the earlier same-day 14-entry traversal omitted the docs folder. On October 25, the 6,426-byte `docs/metadata/main.md` file was retrieved only to check integrity; its SHA-256 and MD5 match the current OSF API. The October 23 local manifest had a malformed 63-character SHA-256 for this path. The documentation file was not read or redistributed; no audio, annotations, coordinate values or model weights were acquired. See the [file-verification record](../research/wytham_file_verification_2026-10-25.json). The authors say the original ~9 TB continuous soundscapes are not shared in the prepared package. Documentation specifies British National Grid nestbox coordinates in `nestboxes.csv` and `main.csv`, and a study-perimeter file. Coordinate values were not inspected; treat them as potentially sensitive and keep public geography coarse. Confirm a distinct task, intended file/metadata scope, held-out-bird evaluation, compute and safe location minimization before use. |
| **NBM nocturnal bird-migration dataset** | 2,077 training recordings and 13,359 time-frequency annotations across 117 species provide a useful example for fine-grained call localization and annotation workflow design. | Detection/species labels do not measure behavior or receiver response. The dataset mixes NBM-Orig CC BY 4.0 audio with per-recording Xeno-Canto terms; annotation/metadata, code and weights need separate rights review. The article's test description says 270 recordings while its detection evaluation says 271; the upload-time cutoff does not establish bird/site independence. Keep it as a detection-methods comparator, not a new communication benchmark. See [`nocturnal-bird-migration-dataset-2026`](../research/nocturnal-bird-migration-dataset-2026/). |
| **Honeybee waggle dance and follower data** | A known movement signal linked to individual tracking, follower behavior and 2019 feeder outcomes; a candidate for an independent, bee-held-out re-evaluation of a narrow existing result. | The paper already reports dance/follower and feeder associations. The archive spans one Berlin observation-hive site across two seasons; its published sample split groups by hour, not by bee or colony. The Zenodo API declares CC BY 4.0 for the dataset; code and models have separate terms. No payload was acquired. |
| **OpenWhistle bottlenose dolphins** | A bounded reproduction of whistle detection or ten-category whistle-type classification; a reviewer could assess whether a carefully specified temporal or individual-held-out extension adds value. | The paper reports about 180,000 whistles (114 hours) across five years from one pod of five dolphins, with 8,354 expert annotations. Its published split holds out recording sessions, not animals; the same small pod spans the splits. The expert labels cover five months of the five-year corpus and are imbalanced. These limits make population generalization weak and do not establish behavior, receiver response or meaning. The pinned repository declares CC BY 4.0 for named dataset releases; verify exact file membership. Code and model weights have separate unresolved terms. Keep metadata-only pending independent cetacean-bioacoustics and ML/statistical review. |
| **Egyptian fruit-bat vocalization corpus** | About 293,000 short recordings and 91,080 video-derived annotations; the 2024 paper reports context prediction on 35,074 filtered calls with subject-independent folds. A role-aware check finds that excluding 122 files with multiple known callers retains 34,815 rows (99.26%), with every context represented by at least eight callers. This supports reviewing a narrowly defined unseen-caller test within the same controlled cohort. | The exact published fold membership is unverified, and the reported work may already answer a similar question. A strict caller/addressee graph is highly connected; the new check is descriptive and lets held-out callers appear as addressees in development data. Sessions, channels, treatment, chamber, uncertain roles and context-label validity remain unresolved. This is a review lead, not a selected benchmark or a meaning test. |
| **ZF-AIM zebra-finch release** | A large, controlled vocal-interaction resource with code/checkpoints and metadata for next-call prediction. Relevant to vocal contingency and turn-taking questions. | It is a 2026 preprint/release; the repository catalog records conflicting dataset-rights declarations, uncertain coverage of the analyzed corpus, and no verified bird-independent split. Prediction of a next call is not decoding its meaning. |
| **El Silencio / BirdCLEF+ 2025** | 770 one-minute soundscapes from seven sites, with roughly 15,000 strongly labeled boxes across four taxonomic groups. Useful for multi-taxon event identification, annotation and soundscape pipeline work. | Labels identify calls/sonotypes, not observed behavior or receiver response. The Zenodo dataset record currently has no displayed license, so keep it metadata-only until component rights are resolved. |
| **Household budgerigars** | A practical candidate for a future passive, human-guided Field Companion workflow if carers and an avian researcher are available. | No reviewed large public household dataset supplies the needed phone recordings plus independently observed context. Do not recruit, collect or upload real observations without protocol, consent, rights, privacy, retention and withdrawal review. |
| **Vervet alarm-call studies** | A strong methods case for separating a call from social context and measuring receiver behavior. The 2023 study found lower speaker-directed looking and vigilance during ongoing intergroup encounters than when none was underway. | The study tested eight adult females from one group across 16 trials, using two exemplars from one male; it observed no predator-specific escape response, and its startle-result wording conflicts internally. Linked data/code terms and contents remain unreviewed. This is a literature/methods comparator, not an open training corpus or first phone-based cohort. |

Counts above describe the source records, not independent sample sizes for every proposed analysis. Files, clips, notes, annotations and animals are different units. Random clip splits can leak bird, household, session, device or site identity; a large record count does not cure that problem. For OpenWhistle, five animals do not support a broad claim about dolphin populations, and an individual-held-out analysis would have only five folds and needs specialist review before it is treated as a useful extension.

## October 25 honeybee file-scope recheck

The official Zenodo v1.0 API lists 11 files totaling **4,870,358,178 bytes** (4.87 decimal GB). This is the deposited file-size sum; the landing page's larger “data volume” figure appears with views/downloads statistics and is not the sum of the record's files. The named `Berlin2019_followers.csv` is **9,171,824 bytes**, above the collection tool's 5 MiB per-file cap. The smaller dance and feeder metadata files have not been shown to support the receiver-outcome question without that follower table. Keep the record metadata-only; do not bypass the cap with direct downloads, another tool or archive splitting. Any later path requires a distinct scientific reason, independent review and separately reviewed acquisition design. No dataset bytes were acquired or inspected.

## Household companion-data check (October 24, 2026)

The reviewed cat, dog and parrot materials sharpen the household decision but do not replace it. [CatMeows](https://zenodo.org/records/4008297) describes 440 sounds from 21 cats and includes context plus cat, owner and session identifiers. Its CC BY-NC 4.0 declaration is not general commercial permission, its contexts are elicited, and the files remain unacquired. The full [dog-bark study](https://aclanthology.org/2024.lrec-main.1432/) reports 16,789 segments from 74 dogs during designed home exposures; the selected classifier associates sound with those induced situations, and the paper describes data access by request rather than a public versioned deposit. Its dog-held-out split does not establish household-, session- or stimulus-independent generalization. The two reviewed [parrot surveys](https://www.nature.com/articles/s41598-022-24335-x) and [2026 name-use study](https://doi.org/10.1371/journal.pone.0346830) provide caregiver-reported phrase/context examples, not a natural-call audio corpus or an independent receiver-response benchmark. Their supporting workbooks have not been inspected.

The [budgerigar Dryad deposit](https://doi.org/10.5061/dryad.fttdz08xr) contains derived call features and separately recorded social observations, but no source call WAVs or shared event timestamps. A separate [2026 edge-monitoring paper](https://doi.org/10.3390/ani16203246) reports year-long vocal-activity monitoring of ten budgerigars; only the publisher abstract was reviewed, and activity detection is not context, caller identity or communication meaning. None of these records establishes that one species is the best scientific or product cohort. Keep budgerigars as a provisional household-usability hypothesis only; keep dataset-based benchmark selection separate and gated by the review packet. The source-linked research-library synthesis is live at [Which companion animal is ready for a first study?](https://metivity.github.io/talk2nature/research/companion-animal-cohort-evidence-2026/) and is linked from the first-animal guide.

## What “start learning” should mean

If Raviv wants one bird and one large corpus to explore first, the current provisional choice is **Great Tit song structure with Wytham**, not because great tits are known to be “more communicative,” but because the prepared corpus has dense song and individual annotations for a bounded methods exercise. This is a prepared-song methods path, not a raw continuous-soundscape reproduction: the authors say the original ~9 TB soundscapes are not shared. The OSF node declares CC BY 4.0 for the dataset record and the setup-code repository separately declares MIT; this does not clear nested provenance, precise wildlife locations, or separate 2025 analysis assets. The complete root inventory has 23 files (14 data and nine docs); the earlier 14-entry same-day snapshot was partial. The current `docs/metadata/main.md` bytes match the OSF API SHA-256 and MD5; the October 23 local snapshot's stored SHA-256 was only 63 characters. That documentation file was downloaded solely for the integrity check and was not read; no audio or annotation file was downloaded. Before any analysis, an independent reviewer should identify a question that improves on existing repertoire/culture studies; define the exact files and fields to use; exclude precise nestbox coordinates and review derived identifiers; and approve a held-out-bird evaluation with suitable baselines. No coordinate values were inspected.

If the goal is a closer link to an established communication system with an observed receiver, **honeybees are a compelling review candidate**: the dance, followers and feeder outcomes are linked in a large public archive. That does not make the case novel or ready to run. The next question is whether a bee-held-out re-evaluation adds value beyond the published work and survives independent insect-behavior and ML/statistical review. For sound-and-context prediction, **bats remain a separate lead**, but their current grouping audit must be resolved before modeling. For the household app, **budgerigars remain a usability hypothesis**, subject to genuine carer access and specialist safeguards.

The newly reviewed NBM collection is a strong bird-acoustics methods example, especially for precise time-frequency call boxes and community annotation. It does not displace Wytham as the provisional song-structure lead or supply receiver/meaning labels. Treat it as a future annotation-format comparison; the current Talk2Nature time-only exports are not equivalent to its time-frequency labels.

## Next gate

1. Use the [consolidated no-data review packet](FIRST_DATASET_REVIEW_PACKET.md) to keep the methods, communication-adjacent and app-cohort questions separate.
2. Ask an independent, species-appropriate reviewer to select or reject the question and label unit (insect behavior for honeybees, avian bioacoustics for bird candidates); ask a separate ML/statistical reviewer to check grouping, leakage, baselines and metrics.
3. Record component-specific rights and intended use for selected inputs. The honeybee Zenodo v1.0 API declares CC BY 4.0 for the dataset, but linked code/models are separate and fine-scale feeder coordinates require minimization. For Wytham, the OSF node declares CC BY 4.0 and setup code is separately MIT, while nested provenance, wildlife-location handling and exact analysis-file scope remain open.
4. Only if those checks pass, freeze the protocol, versioned inputs, grouped split and locked test before a bounded baseline run.

Until then, continue metadata/rights review and synthetic software checks. No outreach is implied by this internal brief; external contact needs action-time authorization. The benchmark remains **NOT READY**.
