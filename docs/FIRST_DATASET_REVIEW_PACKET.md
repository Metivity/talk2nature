# First-data decision: independent no-data review packet

Refreshed October 29, 2026. This packet is for a bounded literature-and-methods review before selecting a Talk2Nature benchmark. No reviewer has been contacted. Small, rights-reviewed annotation/workbook samples were acquired for separate aggregate-only structural checks; no acoustic recordings or model weights have been acquired, admitted to training or run for a benchmark. No benchmark is selected or ready.

## The decision to review

Should Talk2Nature start with a Great Tit song-structure methods exercise, review Brown-throated Parakeet contact-call variation as a reproduction candidate, review an OpenWhistle dolphin whistle-detection/classification task, consider a bee-held-out re-evaluation of honeybee dance/follower data, assess MarmAudio for call-type methods only, choose another communication-adjacent task, or defer modeling until the evidence improves? Reviewers may assess one route only. A useful answer can be **go**, **narrow**, or **defer**; it is not a request for endorsement, partnership, animal recruitment, playback, or human-language translation.

The review needs two distinct kinds of expertise: an independent, species-appropriate behavior/bioacoustics reviewer to assess the question, labels and biological claim; and an independent ML/statistical reviewer to assess the evaluation unit, grouping, leakage, baselines and uncertainty. OpenWhistle needs cetacean-bioacoustics or dolphin-behavior expertise; the honeybee route needs insect behavior or social-insect communication expertise; MarmAudio needs marmoset vocalization or primate bioacoustics expertise. One reviewer may identify a limit in their own area and recommend the other review. Independence, source authorship and relevant recent collaboration must be disclosed before the review is described as independent.

| **Brown-throated Parakeet — contact-call methods path** | Is a reproduction or stress-test of the published acoustic-variation analysis useful under caller/group- and location-aware evaluation? | The study analyzes loud contact calls, not the full repertoire, and has no receiver-response labels. | **Great Tit / Wytham — methods path** | Can a method reproduce expert-marked song-note structure on prepared songs from birds excluded from model fitting? | Authors report 109,963 prepared songs and more than 1.16 million annotated notes. The OSF node declares CC BY 4.0 for the dataset record. The complete current API tree has 23 files totaling 12,184,678,510 bytes (14 data and nine docs); an earlier same-day 14-entry traversal only listed the data/ folder. All normalized paths and sizes match the prior snapshot, but the provider SHA-256 for docs/metadata/main.md differs at the same byte size. No payloads or coordinate values were inspected, and provider hashes were not recomputed. The shared package excludes the original roughly 9 TB continuous soundscapes. A 2025 study already applied deep metric learning to repertoire similarity and song culture, so the task must add value. Author documentation places British National Grid nest-box coordinates in `nestboxes.csv` and `main.csv`. Confirm a distinct task, intended file/field scope, nested provenance, bird-held-out split, prior art, compute and wildlife-location minimization before any use. This is not a behavior or meaning dataset. |
| **Bottlenose dolphin / OpenWhistle — acoustic-structure path** | Is reproducing the whistle-type classification/detection baseline useful, and can temporal or individual-held-out extension be justified with only five dolphins? | The v1 paper reports about 180,000 whistles (114 hours) across five years from one pod of five, with 8,354 expert annotations. The current official project page adds ten-type macro-F1 and other training/evaluation tables; these are not directly interchangeable with the paper's balanced six-class accuracy, and the page does not version-map every row to an exact config/code release. The paper split is session-disjoint, not animal-disjoint. Labels cover five months and do not establish behavior, receiver response or meaning. The pinned author repository declares dataset CC BY 4.0; code and model terms remain separate and unresolved. No audio, labels, code or weights were acquired. Ask independent cetacean-bioacoustics and ML/statistical reviewers to judge usefulness and the exact metric/configuration crosswalk before selecting a reproduction. |
| **Common marmoset / MarmAudio — call-type methods only** | Is any distinct call-type or vocal-event methods question useful within the published one-colony corpus? | The authors report 871,044 segmented vocalizations (253 hours) and six specific model-assisted call-type labels on about 215,000 clips; a 700-clip sample was checked by four experts with model predictions visible. They explicitly say sender identity and production context are missing. The latest Zenodo v7 record declares CC BY 4.0, pinned analysis code declares BSD-3-Clause, and the article is separately CC BY-NC-ND 4.0. Its nine-file deposit totals about 60.4 GB; the error-rate prose/table disagree (9.43%/8.71%). It is a call-type methods resource, not a context, receiver-response or meaning benchmark. No data or code were acquired or run. |
| **Honeybee / waggle dance and follower data — known signal/response path** | Can a bee-held-out re-evaluation add value beyond the published association between dance features, follower behavior and feeder outcomes? | The 2023 paper reports more than 100,000 waggle phases; its manually annotated subset covers 176 videos, 3,278,121 detections and 4,389 bee IDs. The Zenodo v1.0 API declares CC BY 4.0 for the dataset and lists 11 files totaling about 4.9 GB, including more than 46 million 2019 track detections. The study spans one Berlin observation-hive site across two seasons. Its sample-level split groups by hour, not by bee or colony. Fine-scale feeder coordinates are present; linked code/models are separate. No payload was acquired. The existing results are prior art, so novelty must be independently assessed. |
| **Zebra finch / ZF-AIM — controlled vocal exchange** | Is a bounded next-caller, call-token or response-timing analysis scientifically useful, and what would a bird-independent test require? | The preprint's methods report 834,309 calls and 21 birds while a results passage reports 20. The described pair split does not establish disjoint evaluation birds. The separate data record's API says CC BY-SA 4.0 while its description says CC BY-NC; it lists four raw examples and does not establish full analyzed-corpus coverage. Keep metadata-only until those rights, corpus and grouping questions are resolved. Predicting a next call is not decoding its meaning. |
| **Egyptian fruit bat — observed-context association** | Does any narrower context-prediction estimand have a defensible held-out unit? | The source corpus has about 293,000 recordings and 91,080 video-derived annotations. In Talk2Nature's filtered subset, the strict file-plus-emitter and file-plus-known-participant graphs have largest components of 95.31% and 95.56%. A role-aware check excluding 122 mixed-known-caller files retains 34,815 of 35,074 rows (99.26%) and all 11 contexts across at least eight callers each, making a caller-held-out, whole-file estimand worth independent review. It does not establish a split: callers may appear as addressees in development, and exact paper folds and session/date/channel/treatment/chamber joins remain unverified. This is not a receiver-comprehension test. |
| **Budgerigars — Field Companion cohort** | Can a passive phone workflow help carers make observations that an avian researcher would consider useful? | This is a product/usability hypothesis, not a public benchmark. Genuine access, qualified review, an approved protocol, consent, privacy, retention and withdrawal safeguards are not yet established. No participant recruitment or real-data intake is part of this review. |

These routes are not interchangeable. Wytham remains the leading large prepared-song methods candidate; Brown-throated Parakeet is a more direct parrot-specific acoustic reproduction lead but its counts and task novelty are unresolved; OpenWhistle is a large within-pod dolphin acoustic-classification candidate; honeybees offer the clearest reviewed signal-to-follower/feeder link but mostly established prior art and one site; zebra finches are the closest controlled bird vocal-exchange lead; bats offer video-coded context but currently have a difficult grouping structure. MarmAudio adds a strong marmoset call-type methods corpus, but the paper says sender identity and production context are absent. Budgerigars are a separate app path. A larger file count does not decide which question is scientifically strongest.

## Separate route — monk-parakeet known-caller identity, not communication

The 2023 Barcelona study reports 5,599 calls from 229 individually marked monk parakeets over two years and tests caller identity across call types. Its target is known-individual acoustic discrimination; the paper does not test call meaning or receiver understanding. This route may be a narrow methods reproduction, but it is not a first communication benchmark or a substitute for the companion-parrot feasibility cohort.

The existing source review covers the primary article, a versioned supplement and an aggregate join audit. The audit records 808 annotation references across 317 selection-table files; 46 references are unmatched, one appears across files, and 412 matched references expand to multiple waveform rows. These are structural counts only. They do not validate audio alignment, independent call units, labels or a split. Edmond V1 metadata declares MIT for the deposit, while the separately published GitHub selection-table files have not been mapped to archive members; the archive remains unacquired and no model has been run.

The focused question is whether reproducing the published known-caller test would be useful, which grouped evaluation and simple baselines would make it informative, and whether the joins and observer labels support the proposed unit. Reviewers may recommend **go**, **narrow** or **defer**. Any positive recommendation still requires file-level provenance/rights review and a frozen evaluation plan. See the [monk-parakeet evidence note](https://metivity.github.io/talk2nature/research/parrot-data-feasibility/) and its open questions below. No reviewer has been contacted; the packet is not a partnership or data-access request.

## Questions for reviewers

1. **Novelty and value:** Is the proposed question useful and distinct from the cited prior work? What published analysis must be reproduced or surpassed first?
2. **Labels and unit:** What exactly is the target label and unit of analysis—note, song, call, pair, context event, bird or session? Which labels are observed directly and which are inferred or assigned by people?
3. **Generalization and leakage:** What population should the result generalize to? Which birds, pairs, sessions, sites or devices must be held out together? Is there enough independent group structure for that test?
4. **Baselines and uncertainty:** Which simple label-prior, context-only, identity, timing or acoustic baseline is necessary? Which primary metric and uncertainty procedure respect repeated recordings and class imbalance? What outcome would justify stopping?
5. **Rights and data minimization:** Which exact paper, data, annotations, code, model weights and derived fields are needed? What terms govern each asset? For Wytham, can the proposed task avoid raw continuous soundscapes and exact nest-box locations? For OpenWhistle, are the exact files within the dataset releases named by `LICENSE-DATA`, with code and model terms kept separate?
6. **Decision:** Recommend **go**, **narrow**, or **defer** for the specific route you assessed. Name the smallest next check that could change your recommendation and the artifact it needs.

“Cannot assess from the available public record” is a valid conclusion. A reviewer recommendation does not grant rights or authorize acquisition. If the reviewers disagree, preserve both assessments and do not turn the disagreement into a consensus claim.

## Review and data boundaries

The linked evidence notes state review depth, versions, limitations and separate asset-rights status. Please cite the exact note or source sections you assessed, identify your review scope, and disclose authorship or relevant collaboration. A review may be submitted through the [scientific methods review form](https://github.com/Metivity/talk2nature/issues/new?template=scientific-review.yml). That issue is public; do not attach audio, annotations, participant or animal identifiers, private correspondence, unpublished material, credentials or sensitive locations.

This packet authorizes no data acquisition, model execution, animal playback, participant recruitment, private database intake, grant application or partner communication. A positive review would be one readiness input; the project must separately resolve exact rights, approved protocol, frozen grouped evaluation, baselines, a locked test and safe execution before any biological model run. Prediction and acoustic structure remain distinct from meaning or communication.
