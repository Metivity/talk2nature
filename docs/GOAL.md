# Talk2Nature goals

Established September 30, 2026. The public repository and website are launched. Raviv explicitly requested a new data, code and research collection goal on September 30; funding and the scientific pilot remain open.

## Active program: evidence to useful tools to independent adoption

Continue one verifiable cycle at a time: find a concrete research or user need; check primary evidence, access and component-specific rights; add a concise source-linked record; improve the simplest useful app or contributor workflow; validate the change on mobile and in a clean build; publish accurate, indexable pages; then seek independent review through authorized channels. Keep the advanced research path available without making beginners handle schemas or JSON. Do not optimize for the number of papers, features, stars or URLs alone.

The program has four release-facing outcomes: (1) a growing, traceable resource library with reviewed methods, data, code and models kept distinct; (2) a straightforward, reliable Field Companion flow for passive observation and export; (3) clear open-source onboarding and repeatable project checks; and (4) useful, crawlable research pages with verified deployment and honest Search Console reporting. A first ML benchmark is a gated research outcome, not a launch promise: it remains **NOT READY** until the existing data, reviewer, split, baseline and locked-test requirements pass. Current implementation progress and evidence limits are tracked in `docs/STATUS.md`; next research choices are in `docs/RESEARCH_BACKLOG.md`.

### Current next milestone — obtain independent review before selecting a benchmark

Do not choose a species just because a dataset is large. The current evidence separates these paths:

- **Great tits:** Wytham has 109,963 prepared annotated songs and more than one million acoustic units for song-structure methods. The OSF node declares CC BY 4.0 for the dataset record and the setup-code repository separately declares MIT. The complete API tree lists 23 files totaling 12.18 GB (14 data and nine docs); an earlier same-day 14-entry traversal omitted docs. Paths and sizes match the prior snapshot, with one unresolved provider-hash difference for a documentation file. The 2025 metric-learning/repertoire work is close prior art; the original ~9 TB continuous soundscapes are not in the shared package. Documentation identifies British National Grid nestbox coordinates in `nestboxes.csv` and `main.csv`, plus a perimeter file. No file payloads or location values were inspected; keep public geography coarse and treat those fields as potentially sensitive.
- **Bottlenose dolphins / OpenWhistle:** approximately 180,000 whistles (114 hours) from five animals over five years, with 8,354 expert labels and published detection/classification tasks. This is a strong large-audio candidate for bounded acoustic work, not meaning. Its session split includes the same small pod, expert labels cover five months, and the data license applies only to named releases; code and model weights are separate. Keep it in independent review and do not equate its size with population-level evidence.
- **Egyptian fruit bats:** the corpus has roughly 293,000 recordings and 91,000 context annotations, but the current identity/file grouping audit leaves about 95% of records in one connected component; a strict held-out evaluation is not ready.
- **Zebra finches:** the current ZF-AIM release offers a controlled vocal-interaction question, while its exact data rights and bird-independent splits remain unresolved.
- **Budgerigars:** a provisional household-app cohort, conditional on real access and qualified avian review; not a large public benchmark.

- **El Silencio/BirdCLEF:** a useful multi-taxon event-identification methods path, not communication meaning; its Zenodo dataset record does not display a license.
