# First model and dataset decision

Reviewed September 30, 2026; updated October 14. This is a feasibility decision, not an installed environment, benchmark result or legal clearance. No model weights or animal recordings were downloaded.

## Decision

Prefer a small classifier over frozen Perch embeddings for a first **acoustic context-association experiment**, conditional on a suitable species, question and dataset. Compare it with majority-class, simple acoustic-feature and background/context baselines. Do not build a new foundation model or natural-language animal persona. A voluntary parrot interface would require a different experiment and might not need an acoustic model at all.

This choice keeps the initial implementation small and leaves a possible commercial route if the exact artifact, training-data provenance and application terms are verified. It does not establish task performance or an original research contribution. The existing Hoplite workflow already covers embedding search, annotation and classifiers; use or contribute to it where practical.

## October 11 update: animal2vec / MeerKAT is a rare-event reference

The 2026 peer-reviewed paper reports 1,068 hours of meerkat audio and 184 hours of complete event labels, and evaluates event/call-category prediction with precision–recall metrics. This is useful for detector design and for understanding sparse, noisy, multi-label audio. It does not answer the project's first acoustic-context question: the labels are sound/event categories, and the focal tag is source attribution based partly on intensity, spectral change and context, not a communication-meaning label.

Treat the components separately: the paper links the MeerKAT dataset and checkpoints under CC BY-NC 4.0 and animal2vec code under MIT. The dataset and weights remain outside the shared commercial-capable corpus. The sample-level five-fold design was not verified as animal/session grouped; randomized filenames intentionally conceal identity and chronology, which the authors say may be requested. No data, code or weights were acquired or executed. The evidence note and `research/resources.json` preserve separate versions, rights and review limits. AutoResearch remains **NOT READY**.

## Resume gate and first executable milestone

1. Audit source/package provenance and any available recordings separately; select one species and one observable target with a scientific collaborator. Confirm whether the work concerns natural calls or a learned interface.
2. Document original recording rights, human consent where applicable, individuals, sessions, devices/sites, observation provenance and annotation agreement. Check near duplicates and possible pretraining overlap. Decide what can be published separately from what can be analyzed.
3. Freeze the model artifact and dependency environment; record artifact checksums and measured runtime on a small permitted sample. Verify preprocessing and align every crop with observation timestamps.
4. Use the existing manifest validator; additionally hold out relevant sites/devices/time where needed. If groups or class coverage cannot support the chosen evaluation, revise the question or gather appropriate data before reporting accuracy.
5. Predefine metrics, background controls, cluster-aware uncertainty, calibration and abstention. Report failure cases and all prespecified comparisons. A predictive association alone does not establish meaning or two-way communication.

Until these inputs exist, more model integration would commit the project to an untested task. The current code milestone remains the tested metadata/split foundation.

## October 12 update: source separation is an upstream audio question

Bermant's BioCPPNet paper is a useful cross-species methods reference for one narrow stage: separating overlapping vocalizations into estimated source waveforms before downstream analysis. Its study creates mixtures from known animal vocalizations and reports SI-SDR plus a caller-identity classifier for macaques, bottlenose dolphins and Egyptian fruit bats. The reported bat test includes an open-speaker condition with three held-out individuals, but this does not establish performance on uncontrolled phone or field recordings.

This method does not predict interaction context or decode communication. In a future pipeline, keep detection, source separation, caller attribution, observable context and receiver-response experiments as separate tasks with separate labels and evaluations. ## October 22 — Jev / TypeSafe fit for Talk2Nature (no integration)

Jev could eventually help sort **public source metadata** into a human-review queue—for example, a bounded choice among “communication context,” “acoustic detection,” “not relevant,” and “unclear.” It is not a crawler, an audio classifier in the current product, or a source of biological ground truth. Talk2Nature's current bottleneck is still source access, rights, label provenance and qualified interpretation; no Jev call is justified for this El Silencio review.

The official API accepts supplied state plus named Choice, Score and Noul questions and returns typed answers and token usage ([API reference](https://docs.typesafe.ai/api/system-one)). Type safety constrains the answer shape; it does not establish whether a scientific judgment is correct. The vendor's Jev 1.13 notes warn about literal interpretation, long or irrelevant context, adversarial input, option-order sensitivity, and generation limits ([known limitations](https://docs.typesafe.ai/model-jaggedness/jev-1.13)). TypeSafe's October 14 announcement describes image support as experimental, says multimodal performance is worse than text, and says the new features are not yet production-ready ([Jev 1.14 announcement](https://typesafe.ai/blog/jev-1-14)). Treat model version and modality as separate review decisions; do not generalize a 1.13 caveat to an untested later version or treat a vendor confidence value as calibrated on Talk2Nature data.

**Decision:** no client-side API call and no app-model integration. If source-volume needs later justify a small trial, evaluate a local/server-side metadata-only suggestion tool on public or synthetic cases, include explicit `unclear`/`other` outcomes, preserve source links and the model version, compare against simple rules, and keep a human reviewer in control. Do not send recordings, participant observations, exact wildlife locations or private project material. Before such a trial, establish a clean owner-controlled credential handoff, endpoint/model version, input-cost ceiling, privacy terms, and a blinded project-specific evaluation with class-order and prompt-injection cases. No TypeSafe API call or model result is claimed here.

## October 23 — BEANS-Next and ROOTS broaden the benchmark map

The new [October 2026 preprint](https://arxiv.org/abs/2610.10663) describes BEANS-Next as 45 tasks / 37,718 evaluation examples and ROOTS as 44 million audio-language pairs from 6.5 million distinct clips. ## October 24 — human-guided zebra-finch clustering as annotation-workflow prior art

**Question:** can an existing animal-audio workflow help Talk2Nature scale annotation while keeping experts responsible for labels?

**Evidence reviewed:** the complete text of Lee et al. No data archive, code, model weight or supplement was downloaded or executed.

**Finding:** the paper reports 1,454 vocalizations from three isolated zebra finches with independent cluster labels from three experts per bird. Manual-vs-manual mean ARI/NMI were 0.78/0.83, human-refined clustering 0.73/0.81 and automated clustering 0.62/0.71. Authors report approximately 90 minutes per bird for manual work and 45 minutes for semi-automated proofreading. Their evaluation randomly holds out vocalizations within each bird/annotator combination; it does not test unseen birds. The labels represent acoustic clusters, not receiver-validated behavior or meaning. These are paper results, not a Talk2Nature reproduction.

**Provenance and component rights:** the article is listed CC BY 4.0 by ETH Zurich.
