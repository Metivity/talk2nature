# Changelog

This changelog records versioned Talk2Nature source releases. For reproducibility, record the exact commit as well as the release tag.

## v0.1.0 — 2026-10-12

Initial pre-1.0 release of the Talk2Nature public research-software repository.

Includes the Field Companion installable web app; local-first Station and Listen tools; a cited research and resource library; a research atlas; and standard-library Python utilities for annotation summaries, metadata splitting and source catalog checks. Synthetic fixtures support software evaluation without animal recordings or a model download.

This release is an early research and observation toolkit. It does not provide an animal-language translator, a trained Talk2Nature model, autonomous playback, background recording, a native mobile binary, participant-data intake or a hosted research service. Synthetic outputs are not biological findings; third-party data, code and model weights are not included or granted by this release. Interfaces and file formats may change before 1.0.

Original software is Apache-2.0 and original public summaries are CC BY 4.0. Third-party works retain their own rights. This source release does not claim independent scientific validation.
