# Security and privacy reports

Email Raviv at raviv@metivity.com with “Talk2Nature security” in the subject for a suspected vulnerability, accidental exposure or privacy issue. Include the affected public URL or code revision, expected/actual behavior and a minimal synthetic reproduction. Do not send credentials, real participant recordings or exploit results involving someone else's data. Ordinary non-sensitive usability bugs belong in GitHub issues.

Do not publish an active vulnerability or personal data in an issue. We will assess reports and coordinate a correction and public explanation where appropriate. There is no guaranteed response time, bug bounty, penetration-testing authorization or promised safe-harbor agreement. Stop testing if you encounter private data; report the location without copying it.

Only the current main branch and deployed public release are actively maintained. The owner-only backend is a local prototype; a managed public research service is not available. Public audio tools process files in memory, and downloads remain the user's responsibility. Export before closing. Browser lifecycle behavior can still discard a session; real-device verification remains necessary.
